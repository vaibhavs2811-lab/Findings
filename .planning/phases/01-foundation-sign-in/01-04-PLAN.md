## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-19 | Info disclosure | publishable key in GitHub Actions | low | accept | The publishable key is designed to be public; RLS limits anon to the keepalive row |
| T-01-20 | Elevation of privilege | Streamlit Cloud secrets | critical | mitigate | Exactly three keys pasted (URL, publishable key, Gemini key); config.load_settings refuses non-publishable Supabase keys even if pasted |
| T-01-21 | Tampering | keepalive.yml | medium | mitigate | permissions: {} (no repository token), secrets passed via env not inline interpolation, no third-party actions, no checkout |
| T-01-22 | Info disclosure | tracked files in a public repo | high | mitigate | tests/test_repo_hygiene.py scans tracked files for real key material and asserts secrets files are untracked |
| T-01-23 | Info disclosure | Cloud error pages | low | transfer | Community Cloud forces client.showErrorDetails off; the app already maps auth errors to friendly text |
| T-01-SC | Tampering | pip installs on Cloud | high | mitigate | Cloud installs only the pinned requirements.txt (streamlit==1.65.0, supabase==2.32.0) approved in Plan 01 Task 1 |
