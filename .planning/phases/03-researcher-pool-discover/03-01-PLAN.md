## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> Streamlit server | Query param `?id=` and filter inputs are user-controlled |
| authenticated user -> PostgREST | Per-session client with the user's JWT; RLS profiles_select decides visible rows |
| profile text (any user) -> other users' screens | Names, interests and bios are written by other users (or generated) and shown on Discover and profile pages |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information disclosure | Contact email on Discover / profile page | high | mitigate | Explicit CARD_COLUMNS / PUBLIC_PROFILE_COLUMNS with no email; views never touch the contacts table or the contact-email RPC (Task 3 grep gate + AppTest asserting only table "profiles" and no rpc); render_profile called with its email flag off |
| T-03-02 | Information disclosure | Vector and bookkeeping columns over the wire | low | mitigate | Column lists exclude embedding, embedding_hash, embedding_model, methods_hash; unit tests on both constants |
| T-03-03 | Tampering / Spoofing | Markdown/link injection via names, interests, bios | medium | mitigate | User text rendered only with st.text; badge_markdown builds directives from whitelisted stage/methods values only (test with injected stage); unsafe HTML never enabled |
| T-03-04 | Tampering | `?id=` injected into PostgREST filter | medium | mitigate | get_public parses the id as a UUID before any query; invalid ids return None with zero queries (unit test) |
| T-03-05 | Spoofing | Synthetic profiles mistaken for real researchers | medium | mitigate | Orange "Synthetic profile" badge on every synthetic card and profile page plus an explanatory caption on Discover (DATA-03); exactly-once AppTest |
| T-03-06 | Information disclosure | Skip list carried across accounts in one browser session | low | mitigate | skipped_owner tag resets skipped_ids when a different user signs in (AppTest) |
| T-03-07 | Information disclosure | Incomplete profiles listed | low | mitigate | list_public filters is_complete = true on top of the RLS select policy |
| T-03-SC | Tampering | pip installs | high | mitigate | No new packages in this plan; google-genai was pinned and legitimacy-checked in Phase 2 |
</threat_model>
