findings/ai/embeddings.py (no streamlit):
- Constants: EMBED_MODEL = "gemini-embedding-2", EMBED_DIM = 768, EMBED_TEXT_VERSION = "e1", EMBED_TASK_PREFIX = "task: sentence similarity | query: ", EMBED_TIMEOUT_MS = 15000.
- profile_embedding_text(profile) builds newline-joined labelled lines from the behaviour list, after collapsing whitespace. It caps free text at 1500 characters and lists at 15 items of 80 characters, and skips empty lines.
- profile_hash(profile) is the sha256 hex of the model, dimension and text version joined with "|", then a newline, then the text.
- make_embed_client(api_key=None) builds genai.Client(api_key=key, http_options=types.HttpOptions(timeout=EMBED_TIMEOUT_MS)). The key comes from the argument or from GEMINI_API_KEY / GOOGLE_API_KEY in the environment. A missing key raises AIUnavailable.
- embed_text(text, *, client=None) makes one embed_content call with contents=text (a single string) and config=types.EmbedContentConfig(output_dimensionality=EMBED_DIM). It requires exactly one embedding of length EMBED_DIM, L2-normalises it, and wraps any failure in AIUnavailable with a user-safe message. It never logs the text.
- embed_profile(profile, *, client=None) is embed_text(profile_embedding_text(profile), client=client).

findings/services/seed_rows.py (pure):
- seed_uuid(seed_id) is uuid5 over a fixed Findings seed namespace (uuid5 of NAMESPACE_URL and "https://findings.streamlit.app/seed").
- contact_email(profile) builds an NFKD ASCII slug of the name, lowercased, with non-alphanumeric runs turned into ".", capped at 40, falling back to "researcher". It returns slug + "." + seed_id + "@example.org".
- to_profile_row(profile, *, embedding=None, embedding_hash=None, embedded_at=None) maps the seed profile to the profiles columns: id, is_synthetic True, is_complete True, all text and list fields, toggles, methods_suggested = profile methods, methods_override None, methods_reason "Synthetic profile: methods label set by the seed spec", embedding, embedding_model EMBED_MODEL, embedding_hash, embedded_at.
- cosine_report(vectors: dict[str, list[float]]) returns n, mean_pairwise, max_pairwise with its pair, mean_nearest_neighbour and near_duplicates (>= 0.95). Pure Python.

findings/repos/seed_admin.py (service-role only, never imported by app code):
- existing_flags(sb_admin, ids) selects "id, is_synthetic" with .in_("id", ids) and returns a dict.
- upsert_profiles(sb_admin, rows, chunk=25) raises ValueError if any row lacks is_synthetic True, then calls upsert(chunk, on_conflict="id", returning=ReturnMethod.minimal).
- upsert_contacts(sb_admin, contacts) calls upsert(..., on_conflict="profile_id", returning=ReturnMethod.minimal) on the private contacts table.
