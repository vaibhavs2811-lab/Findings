## Phase Goal & Plan Objective

Implement **DATA-01**: Generate a committed, reproducible dataset of 80 diverse synthetic researcher profiles spanning 14 research fields, 6 career stages, 3 methods orientations, and mentoring roles, including 3 anchor evaluation pairs.

## Tasks

### Task 1: Spec Matrix, Domain Validation & Structured Prompting
- Build `findings/services/seed_data.py` with deterministic spec matrix (seed 42), stage quotas, methods rotation, mentoring rules, slug generation, email synthesis (`@example.org`), and give/need list sanitization.
- Build `findings/ai/seed_prompt.py` with Pydantic schemas (`SeedProfileItem`, `SeedBatchResponse`) and prompt templates instructing Gemini to generate fictional, realistic researcher attributes.
- Write unit tests in `tests/test_seed_data.py`.

### Task 2: Seed Generation Script & Committed Dataset
- Build `scripts/seed_generate.py` with 5-item batching, 4.5s rate-limit pacing, resume capability from checkpoint, and deterministic offline generation fallback.
- Run generation to create `data/seed_profiles.json` with 80 valid synthetic profiles and 3 anchor pairs in metadata.
- Validate dataset integrity, quotas, and field completeness with tests.
