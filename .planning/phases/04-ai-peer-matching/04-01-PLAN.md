- template_why(me, cand), which returns one or two plain sentences per D-08:
  - First, up to 3 shared interests or skills, matched case-insensitively and shown in the candidate's casing.
  - If there is no overlap, the candidate's first two interests next to the user's first interest.

- to_item(row, me, *, score=None, why=None, why_source="template"), which returns a card snapshot dict with keys id, full_name, career_stage, methods_effective, interests (first 5), is_synthetic, similarity, score, strength (from score when score is not None, otherwise from similarity), why (template_why when why is falsy) and why_source.
- get_matches(sb, user_id, mode="peer", refresh=False) -> MatchResult. Plan 03 uses refresh; it is accepted now so the signature stays stable. Steps:
  1. Raise ValueError when mode is not in SUPPORTED_MODES (D-15).
  2. Read own profile with profiles.get_own_profile. If it is missing or not is_complete, return no items with INCOMPLETE_NOTICE and make no RPC call.
