## Phase Goal

Deliver AI reranking with grounded peer match explanations (MATCH-01, MATCH-03) and robust fallback to embedding similarity ranking when Gemini is unavailable (MATCH-05).

## Tasks

### Task 1: Structured Gemini Rerank Pipeline & Grounding Guards
- Create `findings/ai/rerank.py` with `RerankResponse` / `MatchItem` Pydantic schemas.
- Build prompt formatting with `<me>` and `<candidate id="cN">` blocks, anti-injection system prompt, and token caps.
- Implement `validate_why` cross-candidate leakage and grounding check.
- Implement `rerank_candidates` with `FINDINGS_FORCE_AI_FALLBACK` switch support.

### Task 2: Matching Service Integration & Fallback Ladder
- Connect `rerank_candidates` inside `findings/services/matching.py`.
- Handle `AIUnavailable` and exceptions by falling back to embedding-ranked items with `FALLBACK_NOTICE` and `source="embedding"`.
- Update `views/matches.py` to display fallback notice and caption appropriately.

### Task 3: Unit and AppTest Verification
- Add `tests/test_rerank.py` testing schemas, prompt formatting, score clamping, cross-candidate guard, and fallback switch.
- Update `tests/test_matching.py` with tests for the live AI path, forced fallback, and AppTest display.
