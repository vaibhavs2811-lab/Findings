## Phase Goal

Deliver match caching, connection-aware filtering, 4-rung fallback ladder, UI refresh with cooldown, and anchor profile evaluation report (MATCH-01, MATCH-04, MATCH-05).

## Tasks

### Task 1: Matches Repository & Cache Layer
- Create `findings/repos/matches.py` with:
  - `get_cached_matches(sb, user_id, mode) -> dict | None`
  - `upsert_cached_matches(sb, user_id, mode, match_key, source, results)`
  - `get_connected_profile_ids(sb, user_id) -> set[str]`
- Compute `match_key = sha256(canonical profile + mode + RERANK_PROMPT_VERSION)`.

### Task 2: Fallback Ladder & Cooldown Integration in matching.py
- Implement 4-step ladder in `findings/services/matching.py`:
  1. Fresh cache check (skip if `refresh=True`).
  2. Live AI rerank -> on success, upsert cache (`source='ai'`).
  3. Stale AI cache fallback -> if live AI fails and prior `ai` cache exists, return stale results with notice.
  4. Embedding-only fallback -> upsert cache (`source='embedding'`) with `FALLBACK_NOTICE`.
- In `views/matches.py`: Add "Refresh matches" button with 60-second session cooldown.

### Task 3: Anchor Evaluation Script & Unit Tests
- Create `scripts/eval_anchors.py` generating `docs/eval/anchor-top3.md`.
- Add test suite in `tests/test_matches_cache.py`.
- Run full verification.
