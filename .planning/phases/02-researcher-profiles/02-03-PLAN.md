## Phase Goal

**As a** signed-in researcher, **I want to** create, save and edit my own profile (career stage, mentoring toggles, give/need fields) and see an AI-suggested methods badge I can override, **so that** Findings has what it needs to match me with the right collaborators and mentors.

This plan's slice: Save now triggers the hash-gated Gemini methods suggestion from 02-02. The profile shows the badge with its reason and source, and the user can override it. A live second-account probe proves that nobody can write someone else's profile.

## Planner Assumptions

- PA2-10: The override control sits in the read-only view, right under the card, and saves straight away (RESEARCH Open Question 1). Save never sends `methods_override`, so a new AI suggestion cannot overwrite the user's choice.

- PA2-13: The probe account is created in the dashboard with Auto Confirm. The script does not call `sign_up`, which keeps it deterministic.
